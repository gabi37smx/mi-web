Portfolio personal

Individual En curso

Web personal con temática de escalada. HTML, CSS y JS puros, sin frameworks. La vía como metáfora: cada sección es un movimiento, cada presa un logro.

  • HTML5
  • CSS3
  • JavaScript
  • Node.js
  • MongoDB
  • Git
Ver código →

Problema

Necesitaba una marca personal para darme a conocer, una ventana a quién soy y, a la vez, un proyecto donde aplicar todo lo aprendido durante 1º DAM.

Solución

Web construida con HTML, CSS y JavaScript puros, sin frameworks. Backend propio con Node.js y Express, base de datos MongoDB y envío de emails con Resend. Frontend desplegado en GitHub Pages y backend en Render.

Resultado

Web online accesible desde cualquier dispositivo, con formulario real que envía emails, panel de administración, tres idiomas, widget del tiempo en directo y certificaciones. Todo versionado con Git a lo largo de más de 25 commits.

App de gestión de cementerio

Individual En diseño

Aplicación multiplataforma para llevar el registro de difuntos, pabellones, zonas y toda la información asociada a un cementerio municipal. Nace de mi trabajo actual como oficial de mantenimiento: conozco el problema desde dentro.

  • A definir
  • Base de datos
  • Multiplataforma
Ver código →

Problema

En el Ayuntamiento de Ollería, donde trabajo como oficial de mantenimiento, la gestión del cementerio se hace hoy con papel y hojas de cálculo. Encontrar dónde está enterrada una persona, consultar qué pabellones están libres o cuadrar los entierros es lento y propenso a errores.

Solución

App multiplataforma con una base de datos real, diseñada desde dentro. Conozco el cementerio, a los compañeros que la van a usar y la información que necesitan en cada momento del día a día.

Resultado

En fase de diseño. El objetivo es digitalizar el proceso para que cualquier compañero del ayuntamiento consulte la información sin depender de mí y se reduzcan los errores humanos.

Aprender valenciano con IA

Individual En diseño

App para aprender valenciano con un agente de IA entrenado: corrige textos, propone ejercicios y prepara para los niveles oficiales B1, B2, C1 y C2. La idea nace porque las herramientas actuales para aprender valenciano son muy limitadas.

  • IA
  • Agentes
  • NLP
  • A definir
Ver código →

Problema

Quiero aprender bien mi idioma materno, el valenciano, y preparar los exámenes oficiales (B1, B2, C1 y C2). Las apps actuales no cubren todas las destrezas de estos exámenes ni permiten entrenar de forma personalizada con corrección real de textos.

Solución

App con un agente de IA que corrige textos, propone ejercicios, adapta el nivel y prepara cada destreza del examen oficial. La idea es ofrecer un entrenador personal de valenciano disponible 24/7 y familiarizado con el formato exacto de las pruebas.

Resultado

En fase de diseño. El proyecto responde a la falta de herramientas para aprender bien el idioma, más allá de ejercicios básicos o aplicaciones genéricas que no conocen los exámenes oficiales.

V5

Facturación para electricistas

Individual En diseño

App para electricistas autónomos que usa WhatsApp Business y un agente de IA: el profesional dicta por voz los materiales usados y las horas trabajadas, y el agente calcula el importe, genera la factura y la envía al cliente por WhatsApp. Nace de conocer el sector de primera mano.

  • WhatsApp Business API
  • IA / Agentes
  • Voz (Whisper)
  • Facturación
Ver código →

Problema

Los electricistas autónomos pierden mucho tiempo haciendo facturas a mano. Además, la facturación electrónica obligatoria en España avanza y cada vez es más necesario emitir documentos digitales que cumplan los requisitos legales.

Solución

App basada en WhatsApp Business y un agente de IA. El profesional dicta los materiales usados y las horas trabajadas; el agente calcula el importe, genera una factura con los requisitos legales y la envía al cliente por el mismo chat.

Resultado

En fase de diseño. El objetivo es reducir el trabajo administrativo y permitir que el electricista facture desde el móvil en menos de un minuto, sin abrir un ordenador.
